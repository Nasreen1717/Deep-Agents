# Report Writer Skill

## When to use this skill
Use this skill whenever the user asks you to summarize findings, write a report,
or turn research/notes into a structured document.

## Report structure
1. **Title** — clear, descriptive.
2. **Summary** — 2-3 sentences on the key takeaway.
3. **Details** — organized under headers, using bullet points for clarity.
4. **Sources** — list where information came from, if applicable.
5. **Next steps / Recommendations** — actionable items if relevant.

## Style guidelines
- Use plain, direct language.
- Keep paragraphs short (3-4 sentences max).
- Use headers and bullet points instead of dense paragraphs.
- Do not repeat the same point in different sections.
